# AGORAI — Backend MVP

Backend du MVP **AGORAI**, une plateforme éducative basée sur :
- des **QCM intelligents**
- des **explications via des ensignants**
- des **explications via IA**
- un **moteur de recherche juridique (RAG)**

Cette partie contient **le backend applicatif**, développé avec **FastAPI** et **PostgreSQL**.
